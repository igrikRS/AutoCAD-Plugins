# Назначение программы
Создание листов по рамкам, указанным пользователем в модели, либо автоматическое создание листов по вхождениям заданных блоков или форматок СПДС Graphics.
Выбор формата бумаги и настройка листов производится автоматически. Поддерживаются:
- Стандартные форматы: А0, А1, А2, А3, А4
- Дополнительные форматы: A0x2, A1x3, A3x4, A4x5 и т.п.

Дополнительно:
- для блоков существует поддержка определения поворота по оси Z

## Использование:
1. Скачать архив из папки "Releases" [(ссылка)](https://github.com/igrikRS/AutoCAD-Plugins/raw/refs/heads/master/Releases/LayoutsFromModel.7z)
2. Загрузить плагин командой: "_NETLOAD"
3. Выполнить команду: "igrikCreateLayouts" (алиас "bargLFM")
4. При первом выполнении п.2 необходимо перед созданием листов указать расположение файла шаблона, который должен лежать рядом с файлом *.dll
5. При использовании форматок из блоков, в настройках необходимо указать "Название" и "Тег" блока-рамки

Плагин протестирован на версиях AutoCAD 2016 - 2023.

## Окно выбора действия:
![](https://i.ibb.co/SwqRVPZg/Layouts-From-Model-1.png)

**Автоматический выбор блоков:** [(видеоинструкция)](https://youtu.be/AQxPH2vl6Ms)
> - Автоматическое создание листов по всем блокам на чертеже с сортировкой их по номеру листа.
> - Нумирация листов берётся из блоков, сортируется от большего к меньшему.
> - Блоки без номера листа, или расположенные на непечатываемых слоях - игнорируются.
> - Присутствует поддержка блоков, повёрнутых вокруг оси Z.


**Автоматический выбор форматок СПДС:**
> - Автоматическое создание листов по всем СПДС форматкам на чертеже с сортировкой их по номеру листа.
> - Нумирация листов берётся из блоков СПДС форматок, сортируется от большего к меньшему.
> - Форматки без номера листа, или расположенные на непечатываемых слоях - игнорируются.

**Ручной выбор блоков/форматок СПДС:** [(видеоинструкция)](https://youtu.be/QwTcPV1HtXE)
> - Ручной выбор каждого блока или рамки-СПДС.
> - Масштаб определяется автоматически.
> - Сортировка определяется в порядке выбора блока или рамки-СПДС.
> - Номер листа берётся простым увеличением от первоночально указанной величины. Номер листа из блока/форматки - игнорируется.
> - Присутствует поддержка блоков, повёрнутых вокруг оси Z.


**Ручной выбор рамкой:** [(видеоинструкция)](https://www.youtube.com/watch?v=BsCouHhkMyI)
> - Ручной выбор каждого формата листа с указанием 2х угловых точек и масштаба/формата.
> - Масштаб определяется указанием длинной стороны штампа.
> - Сортировка определяется в порядке указания рамок.
> - Номер листа берётся простым увеличением от первоночально указанной величины.


**Отсортировать существующие листы:**
> Плагин автоматически отсортирует все существующие листы в порядке возрастания

**Удалить существующие листы:**
> Плагин автоматически удалит все существующие листы.

> Замечание: так как AutoCAD запрещает удаление всех листов в dwg файле, автоматически будет создан лист "Y"

**Настройки:**
> Вызов диалога конфигурации программы

**Шаблон:**
> Позволяет указать где расположен шаблон форматов листов "lfmtemplate.dwt"

## Конфигурация:
![](https://i.ibb.co/RTSvs3tk/Layouts-From-Model-2.png)

**Префикс:**
> Префикс имени создаваемого листа.

**Суффикс:**
> Суффикс имени создаваемого листа.

**Точность определения форматов:**
> Отвечает за точность определения форматов. Суть в том, что форматки иногда бывают примерно  по госту. Таким образом, если указываемая форматка больше гостовского размера (уже после скалирования) на указанный размер - будет выбран соответствующий формат бумаги. Значение - целое число. По умолчанию = 10 мм

**Блокировать созданные видовые экраны:**
> По окончанию выполнения команды по созданию листов все видовые экраны на каждом листе будут заблокированы на изменение.

**Ручной выбор с указанием формата листа:**
> Определяет способ указания масштаба листа.
> - если опция ВКЛ: необходимо будет указывать формат листа из диалога выбора А3, А4 и т.п. Дополнительные форматы А3х3 или А3х4 определяться атоматически на основании указания А3 и т.п.
> - если опция ОТКЛ: необходимо будет указывать размер длинной части штампа. По этому размеру будет вычисляться масштаб листа, и соответсвенно ему подбираться необходимый формат листа А3 или А3х3 и т.п.

**Имя блока-рамки:**
> Название блока, по которому будет производиться автоматический поиск всех блоков с данным именем в пространстве модели, и с последующей сортировкой по имени тега (см.ниже) и созданием листов. Необходим только для команды "Автоматический выбор блоков".

> Важно! Блоки на "непечатаемых слоях" будут проигнорированны и для них листы создаваться не будут.

> Для удобства по кнопке "+" можно просто выбрать блок и указать номер тега этого блока из предложенного списка. 

**Имя тега в блоке:**
> Название тега в блоке, по которому будет производиться сортировка создаваемых листов. Необходим только для команды "Автоматический выбор блоков".

> Важно! Блоки с пустым тегом будут проигнорированны и для них листы создаваться не будут.

**Коэффициент масштаба для блоков**
> Этот коэффициент необходим для правильного вывода блок-рамок на листы, вычерченных в пространстве модели не в масштабе 1:1. Если у вас блоки вычерчены не 1:1, то необходимо будет вводить корректировку масштаба через этот коэффициент.
> В подавляющем большинстве случаев необходимо оставить значение по умолчанию равное "1".

## Опции ком. строки:
**Undo**
> Отменить выбор последней рамки.

**Newscale**
> Задать новый масштаб рамки.

**Process**
> Выполнить создание листов.

**Configuration**
> Вызвать диалог конфигурации.

**TemplateSelect**
> Выбрать шаблонный файл. Переменная FILEDIA влияет на вид запроса (можно использовать в макросах).

## Формирование предварительного списока настроек листа, с форматами бумаги.
Программа формирует список настроек печати либо из выбранного шаблона, либо, при отсутствии шаблона, на основе форматов DWG To PDF.pc3. Эти два источника не объединяются.

## Прилагаемые файлы архива:

**LayoutsFromModel2016.dll**
> Плагин для AutoCAD версий 2016, 2017.

**LayoutsFromModel2019.dll**
> Плагин для AutoCAD версий 2018, 2019, 2020.

**LayoutsFromModel2021.dll**
> Плагин для AutoCAD версий 2021, 2022.

**LayoutsFromModel2023.dll**
> Плагин для AutoCAD версии 2023.

**"lfmsettings.xml"**
> Основной файл конфигурации. Хранит настройки плагина.

**"lfmtemplate.dwt"** 
> Содержит уже настроенные листы, которые использует плагин.

**Папка "Plotters"**
> По умолчанию пользователю не требуется. Но при необходимости используется для внесения изменений в файл "lfmtemplate.dwt"
